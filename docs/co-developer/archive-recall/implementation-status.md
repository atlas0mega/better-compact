# Archive-and-recall implementation audit (work in progress)

This checklist tracks evidence, not release approval. The latest user corrections
at the top of `specification.md` supersede historical percentages and budgets.
The active local configuration uses a 25% best-effort target, a 15%-above-target
last-resort tolerance, seven shared Luna calls, 28k fallback reasoning, and 15k
tool-result retention. Seven-day private-archive expiry remains enabled.
